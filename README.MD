# AI-Painter
## Описание сайта
В данном проекте вы посоревнуетесь с ИИ в рисовании. Вы будете рисовать, а он угадывать или наоборот.
## Примеры запуска оффлайн версии сайта
Чтобы запустить проект оффлайн надо скачать архив из репозитория. Разархивировать его и запустить html-файл
## Где найти сайт в интернете
Этот сайт можно найти по [ссылке](https://gipocrat.github.io/AI-Painter/)
## Идеи для улучшения сайта
Можно подключить дополнительные библиотеки для разнообразия рисования. Добавить побольше кистей через `js`. Можно добавить вызов `OpenAI` для угадывания.
